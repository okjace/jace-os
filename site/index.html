Familiar from the first click

If you've used Windows, you already know how to use Jace OS. If you've used Arch, you'll find everything you love underneath.

Windows-style windows

Minimize, maximize and close on the right. Drag to the top to maximize, to a side to snap. Alt+Tab, Win+arrows and Alt+F4 all work.

A start menu on the Windows key

Tap the Windows key: pinned apps, every app, and search as you type. Make it yours in Settings: where it opens, its size, layout and what's pinned.

A top bar inspired by niri

Floating rounded islands: start button, desktops and open windows on the left, the clock in the middle, status and your Jace account on the right.

One Settings app for everything

Wi-Fi, Bluetooth, displays, sound, virus protection, wallpaper, start menu, every keyboard shortcut, keyboard, power, date and time, default apps, users and updates, all in one place.

Secure without trying

Linux, security fixes and your apps update by themselves in the background. You never have to open a terminal.

Built-in virus protection

Real-time protection scans downloads and new files as they arrive and quarantines threats. There's also a daily scan, plus quick and full scans in Settings.

Get apps right in Settings

Search Jace Store, Flathub and the Arch repositories from Settings → Apps and install with one click. They show up in Jace Store's My apps too.

AppImages just work

Double-click an AppImage to open it. Right-click it and choose Install to add it to the start menu, with its own icon.

Wayland all the way

A modern Wayland desktop (labwc) with screen sharing, fractional scaling and portals, and XWayland for older apps.

What's Jace?

Updates install themselves

Jace OS checks every few hours while you're plugged in and installs everything quietly.

  • The newest Linux kernel and security fixes from Arch Linux
  • New versions of Jace Launcher, Jace Social, Jace Store and Zen Browser within hours of their release
  • Flatpak apps and virus signatures too
  • The two newest versions of everything stay cached, so a bad update can be undone
  • See and install updates yourself any time in Settings → Updates

Install Jace OS

You need a USB stick (8 GB or bigger) and an internet connection.

  1. Download the ISO

    Get the newest jace-os ISO from GitHub. If it comes in parts, join them first (the release notes show how).

  2. Write it to a USB stick

    Use balenaEtcher or Rufus on Windows or macOS, or dd on Linux. This erases the stick.

  3. Start your computer from the USB stick

    Open your computer's boot menu (often F12, F11 or Esc while it starts) and pick the USB stick. Choose Try Jace OS to use it straight from the USB stick without changing anything, or Install Jace OS.

  4. Install it

    The installer asks for your language, keyboard, the disk to use (with optional encryption), your name and a password. Then it installs Jace OS with the newest Jace apps and Zen Browser. Want to keep Windows too? Use Advanced install.

Already on Arch?

Add the Jace OS repository to /etc/pacman.conf, then install the desktop and apps and choose “Jace OS” on your login screen.

[jace-os]
SigLevel = Optional TrustAll
Server = https://github.com/okjace/jace-os/releases/download/repo
sudo pacman -Syu jace-os jace-launcher-bin jace-social-bin jace-store-bin zen-browser-bin yay-bin
